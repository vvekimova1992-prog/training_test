# Arctic academic website — Valentina Ekimova

This branch contains a static personal academic website created from the October 15, 2026 CV.

## Publishing with GitHub Pages

Go to repository Settings → Pages, select Deploy from a branch, select the arctic-academic-website branch and / (root) folder, then Save.

Expected public address after GitHub confirms deployment: https://vvekimova1992-prog.github.io/training_test/

## Pages

index.html: home, research, fieldwork, selected publications, teaching, about and contact.
cv.html: concise, print-friendly web CV, not the complete ten-page source PDF.
